Что делает код: заводится вектор result для ответа, проходим циклом по всем числам из nums, для каждого числа пытаемся найти подходящую строку в result, для этого идём по всем строкам result и внутри каждой строки ищем совпадение с текущим числом, если в строке такого числа нет то добавляем его туда и помечаем placed как true и выходим из цикла, если после обхода всех строк число так и не удалось никуда положить то создаём новую строку, кладём туда число и добавляем эту строку в result, в конце возвращаем result.


Как я решал: подумал что нужно просто жадно раскладывать числа по строкам, для каждого числа ищем первую строку где его ещё нет и кладём туда, потому что в одной строке не должно быть одинаковых чисел, если ни в одну существующую строку положить нельзя значит все строки уже содержат это число и нужно создать новую строку, так мы используем минимальное количество строк потому что каждый раз кладём число в уже существующую строку если это возможно.
