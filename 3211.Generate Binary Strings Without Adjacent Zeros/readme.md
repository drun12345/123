Что делает код: заводится вектор result для ответа, перебираем все числа mask от 0 до 2 в степени n минус 1, для каждого mask строим строку s длиной n где каждый бит числа превращается в символ, если бит равен 1 то добавляем '1' иначе '0', потом проверяем строку на условие что нет двух нулей подряд, для этого идём по строке и если видим что s[i] и s[i+1] оба равны '0' то помечаем ok как false и выходим из цикла, если строка прошла проверку то добавляем её в result, в конце возвращаем result.
