Что делает код: заводится переменная count для подсчёта сколько раз встретилась цифра, проходим циклом по всем числам из nums, для каждого числа берём его последнюю цифру через num % 10, если она равна искомой digit то увеличиваем count на 1, потом убираем последнюю цифру через num = num / 10, так продолжаем пока число не станет нулём, в конце возвращаем count.


Как я решал: подумал что нужно просто разобрать каждое число на отдельные цифры и посчитать сколько из них равны заданной, для этого беру остаток от деления на 10 чтобы получить последнюю цифру, сравниваю с digit, потом делю число на 10 чтобы отбросить эту цифру и перейти к следующей, так прохожу все цифры каждого числа и складываю совпадения в общий счётчик.
